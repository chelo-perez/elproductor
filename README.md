# El Productor

Juego web: girá el título, dá vuelta las cartas y estrená la película.

## Correr local
    npm install
    npm run dev

## Deploy en Vercel
1. Subí esta carpeta a un repo de GitHub (org `toulousepilates` o personal).
2. En Vercel: New Project → importar el repo. Detecta Vite solo. Build: `npm run build`, output: `dist`.
3. Listo. Cada push a `main` redeploya.

Reemplazá `public/og.png` (1200×630) e `icon-192.png` / `icon-512.png` por los definitivos antes de compartir en redes.
